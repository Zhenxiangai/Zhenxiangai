## 你好，我是臻香 👋

AI 工具实践者与独立构建者，关注 **AI Agent、个人知识系统、本地模型与工作流自动化**。

我喜欢把复杂的开源工具真正部署起来，再把踩坑过程整理成普通人也能复用的方法。

- 🧠 正在探索可持续成长的个人 AI Agent
- 🗂️ 研究 Agent 记忆、RAG 与个人知识库
- 🧩 使用 Codex、Hermes 与飞书搭建自动化工作流
- 🛠️ 持续记录部署过程、真实问题和解决方案

## 🌱 正在积累

- 将 Hermes、Codex 与本地模型的部署经验整理成公开文档
- 把日常 AI 工作流沉淀为可复用的配置、Skill 与 SOP
- 用真实项目验证 AI 工具，而不只停留在工具介绍
